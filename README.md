# Lili Puzzle

An offline Android jigsaw puzzle for 4×4 and 6×6 boards.

## Features

- Jetpack Compose UI
- 4×4 and 6×6 difficulty levels
- Piece swapping and snapping
- Timer and move counter
- Android photo picker

## Build

Open this repository in Android Studio, allow Gradle to sync, and run the `app` configuration on an emulator or Android device.

```bash
./gradlew assembleDebug
```

The APK will be in `app/build/outputs/apk/debug/app-debug.apk`.
